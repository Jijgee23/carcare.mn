# Засварын хуудасны хандалтын хүрээ

Засварын хуудасны харах болон засах эрхийг Role тохиргоонд тусад нь сонгоно.

| Хүрээ | Үйлдэл |
| --- | --- |
| Эрхгүй | Засварын хуудас харах, засах боломжгүй |
| Өөрийн | `assignedToId` нь тухайн ажилтны ID-тэй хуудсанд үйлчилнэ |
| Салбар | Нэвтэрсэн ажиллах салбарын хүрээнд байгаа бүх хуудсанд үйлчилнэ |

Засах хүрээ харах хүрээнээс давж болохгүй. Сервер талын шалгалт энэ нөхцөлийг
үргэлж мөрдөнө. `orders.assignable` нь хариуцагч болгож сонгох эрх бөгөөд харах
эсвэл засах хүрээг өөрөө олгохгүй. Хариуцагч оноох нь `orders.assign` эрхээр
хамгаалагдана; `orders.assignable` нь зөвхөн тухайн ажилтан өөрөө хариуцагч
болох боломжтой эсэхийг илэрхийлнэ.

Өмнө хадгалагдсан Role-уудын `orders.view` болон `orders.edit` permission нь
Салбарын хүрээ гэж үргэлжлэн тооцогдоно. Шинэ Өөрийн хүрээний permission-ууд нь
`orders.viewOwn` болон `orders.editOwn` юм. Эдгээр нь өгөгдлийн сангийн өөрчлөлт
шаардахгүй.

`orderReadWhere` нь зөвхөн order-ийн хүрээний where хэсгийг буцаана. Tenant,
салбар болон бусад бизнесийн шүүлтүүрийг дуудагч тал заавал давхар хэрэглэнэ.
